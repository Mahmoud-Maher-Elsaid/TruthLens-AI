# Real non-demo examples

Files in this directory are generated by `ml/validation/run_real_end_to_end.py` from actual local embedding, FAISS, cross-encoder reranking, and NLI verifier inference. They are distinct from deterministic fixtures under `data/fixtures/demo-audit.json`. Each file includes the expected verdicts, actual verdicts, whether they matched, measured latency, pipeline checks, and the structured API report.
