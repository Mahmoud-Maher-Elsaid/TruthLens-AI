# Benchmark artifacts

Evaluation scripts write measured JSON files here. The selected baseline, fine-tuned, experiment-comparison, model, RAG, quantization, system-latency, and real end-to-end artifacts are eligible for Git. Other generated JSON remains ignored pending review. The 180-sample comparison in `experiment2_verifier_comparison.json` is the current fair held-out verifier comparison; the 90-sample baseline and fine-tuned files record earlier experiments. `experiment3_verifier_comparison.json` records the completed multi-evidence Experiment 3 result: checkpoint 400 scored accuracy 0.6444 and macro F1 0.6233 on the same frozen 180-row protocol, so it was not promoted. The web page currently displays older individual files, so read sample counts before comparing cards. The real end-to-end summary records 6/6 expected-case matches on the defined real end-to-end validation suite, with detailed fixtures under `data/fixtures/real_examples/`. It is not a general model-accuracy result.
